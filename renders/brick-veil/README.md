# Brick Veil — developed concept set

This four-view set develops the earlier Brick Veil material study against the
actual Schorisse property photographs. It is visual pre-design material, not a
measured architectural proposal.

## Fixed design logic

- One barn volume: 17.0 m long × 7.5 m wide.
- Eaves: 3.2 m; ridge: 5.2 m; symmetrical roof pitch: approximately 28.1°.
- Front: double-height living, dining and kitchen behind the glass gable.
- Middle: transition and stair.
- Rear: bedrooms, bathroom/service rooms and recessed courtyard entrance.
- Optional loft: partial open mezzanine above only the rear 7–8.5 m, with a
  concept floor around +2.40–2.45 m.
- No annex, canopy, dormer, raised roof, full second storey or projection into
  the tractor lane.
