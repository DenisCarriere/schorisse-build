- `birdseye-orientation-markup.png` — owner-supplied orientation authority:

  end, red marks both long walls, and green marks the courtyard entrance.

The dry grass may be shown as healthy green. Permanent hardscape, planting,
access routes and neighboring/retained buildings must not move in design
visualizations. The bird's-eye markup fixes site relationships; the generated
model and `models/design.json` fix building geometry.
